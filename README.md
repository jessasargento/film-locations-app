# Film Location Explorer

Streamlit app for exploring `film_location_reference.csv`.

## Run locally
    pip install -r requirements.txt
    streamlit run app.py

## Deploy (Streamlit Community Cloud)
1. Push this folder to a GitHub repo (CSV is ~24 MB, fine under GitHub's 100 MB limit).
2. Go to share.streamlit.io -> New app -> pick the repo, branch, and `app.py`.
3. Deploy.
